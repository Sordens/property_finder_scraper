# PropertyFinder.ae Scraper

## Стек
- **Playwright** — браузерная автоматизация (обходит JS-рендер и часть защиты)
- **PostgreSQL** — хранилище с upsert (дубли не страшны)
- **Asyncio** — параллельные воркеры для обогащения телефонами

## Установка

```bash
pip install playwright psycopg2-binary
playwright install chromium
```

## БД
```sql
-- Создать базу
CREATE DATABASE propertyfinder;
```
Потом скрипт `init_db()` создаст таблицы автоматически.

## Запуск

```bash
# 1. Основной скрапер (собирает все листинги)
python scraper.py

# 2. Обогащение телефонами (параллельно или после)
python enrich_phones.py

# 3. Экспорт в CSV
python export.py
```

## Архитектура

```
scraper.py
  ├── Playwright открывает страницу поиска
  ├── Перехватывает XHR/fetch ответы (API данные)
  ├── Парсит __NEXT_DATA__ (Next.js SSR)
  ├── Fallback: DOM парсинг карточек
  ├── Upsert в PostgreSQL
  └── Сохраняет state (возобновление после краша)

enrich_phones.py
  ├── Берёт записи без телефона из БД
  ├── Открывает страницу объявления
  ├── Кликает "Reveal number"
  ├── Перехватывает API ответ с телефоном
  └── Обновляет запись в БД
```

## Анти-бан меры
- Случайные задержки между запросами (2-5 сек)
- Большие паузы каждые 50 страниц (30-60 сек)
- Скрытие webdriver флага
- Реалистичный User-Agent и viewport

## Важно
- Сайт использует CloudFlare — возможны CAPTCHA при агрессивном скрапинге
- Телефоны требуют клика на Reveal (иногда требует авторизации)
- При бане — увеличь DELAY_MIN/DELAY_MAX в конфиге
- Рекомендую запускать с VPN / proxy rotation для 70k+ объявлений

## Ориентировочное время
- 70,000 листингов × ~3 сек = ~60 часов на листинги
- Телефоны: отдельно, 2 воркера × ~3 сек = ~30 часов
- Итого: ~3-4 дня непрерывной работы
